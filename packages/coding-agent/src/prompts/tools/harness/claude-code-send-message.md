Send a message to another agent. `to` is an agent name from ListAgents or a background agent id, or `"all"` to broadcast to every live peer; `message` is plain text. Delivery is immediate and wakes an idle or parked recipient; the reply confirms delivery or names why it failed. `summary` is a transcript label and is not transmitted. `notify_when_idle` is not available in this build; leave it unset.
