Waits on a backgrounded `exec` cell and returns its completion. Use `wait` only after `exec` returns `Script running with cell ID ...`. `cell_id` identifies the running cell. The wait returns the first background result to settle (the cell's completion once it finishes) or an incoming message; if another result arrives first, call `wait` again with the same `cell_id`. `yield_time_ms` and `max_tokens` are accepted but not applied. `terminate` is not available in this build; stop a running cell with interrupt_agent.
