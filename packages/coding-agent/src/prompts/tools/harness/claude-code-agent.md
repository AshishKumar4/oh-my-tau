Launch a subagent to handle a bounded task. `prompt` is the complete, self-contained assignment; `description` is a short label. `subagent_type` selects an agent definition (omit for the default worker); `"fork"` forks yourself — the agent inherits your full conversation context and runs as the default worker. `isolation: "worktree"` runs the agent on its own git worktree when task isolation is enabled. `model` overrides are not available; the agent definition owns its model. When background execution is enabled the call returns a job id immediately; use TaskOutput to wait on it and SendMessage to steer it.
