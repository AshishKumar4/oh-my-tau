Lists the agents you can SendMessage to: every live (running or idle) agent in this session, one row each with its name, status, kind, parent, and last activity. Names are the address: send with `SendMessage({to: "<name>", message: "..."})`, copying the name exactly as a row prints it. Finished agents that were parked are not listed; a message to one by name still resumes it, and `Read history://` lists every agent, parked ones included.
