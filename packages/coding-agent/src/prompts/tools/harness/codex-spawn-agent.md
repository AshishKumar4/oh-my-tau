Spawns an agent to work on the specified task. `task_name` becomes the agent's id; refer to it by that name in send_message, followup_task and wait_agent. `message` is the complete, self-contained assignment. `fork_turns` controls inherited context: `all` (the default) forks your whole conversation, `none` starts blank, and a positive integer string like `3` forks only the most recent turns. `model` overrides are not available; the agent definition owns its model. `reasoning_effort` (low, medium, high, xhigh, max, ultra) is honoured only when task effort selection is enabled in this session. Only call this tool for a concrete, bounded subtask that can run independently alongside useful local work; otherwise continue locally. When background execution is enabled the call returns a job id immediately and the agent's final answer arrives through wait_agent.
